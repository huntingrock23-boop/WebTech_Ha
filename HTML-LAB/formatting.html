HTML Text Formatting

This document demonstrates various HTML text formatting elements used to change visual styling or add semantic meaning to web text.

HTML Formatting Elements

b Element

The b element defines bold text without giving it special semantic importance.

Example: The quick bold fox jumps over the lazy dog.

strong Element

The strong element defines text with strong importance or urgency.

Example: HTML stands for HyperText Markup Language.

i Element

The i element defines text in an alternate voice or mood, such as technical terms or foreign phrases.

Example: The term Homo sapiens refers to modern humans.

em Element

The em element defines emphasized text that changes stress meaning when read aloud.

Example: You must complete your assignment on time.

u Element

The u element represents text with an unarticulated line, commonly used for proper names or misspelled text.

Example: Please correct the mispelled word in the paragraph.

mark Element

The mark element defines text that is marked or highlighted for reference purposes.

Example: Remember to buy milk when visiting the grocery store.

small Element

The small element defines smaller text, typically used for side comments, legal disclaimers, or copyright notices.

Example: Monthly Subscription Fee $10 (Terms and conditions apply).

del Element

The del element represents text that has been deleted or removed from a document.

Example: The sale price is $50.00 now reduced.

ins Element

The ins element represents text that has been inserted into a document.

Example: The new price is $29.99 for a limited time.

sub Element

The sub element defines subscript text, rendered slightly below the normal line.

Example: Water consists of chemical compound H2O.

sup Element

The sup element defines superscript text, rendered slightly above the normal line.

Example: The energy formula is E = mc2.
